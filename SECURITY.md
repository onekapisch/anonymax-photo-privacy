# Security and privacy

## Report a security issue privately

Write to **support@onekapisch.com** with "AnonyMax security" in the subject. Please do not open a public issue for a security problem.

Helpful details: the app version (for example 1.0 (7) on Mac or 1.0 (15) on iPhone and iPad), your device and system version, and the steps to reproduce. **Never send real photos of other people, real number plates or personal documents.** Describe what you saw, or make a test picture with invented details. We will ask for more if we need it. There is no promised response time.

Of special interest:
- a cover that lets the hidden content be read back, recovered or guessed better than chance;
- hidden data (location, device, dates, captions) left in a saved copy that AnonyMax reported as removed;
- any network connection made by the app.

## How AnonyMax handles your photos

- **Private & Offline.** Finding, covering, removing hidden data and the second check run on your device. AnonyMax works without an internet connection.
- **No account.** You open the app and use it.
- **Your original stays.** AnonyMax saves a covered copy; the original is left unchanged unless you choose to replace it.
- **The cover is not a blur.** A blur or pixelation keeps a trace of what it hides. AnonyMax builds every cover without using the hidden pixels, and a read-back attack runs as a leak test in every build. See [How it works](https://anonymax.app/how-it-works/).

The full privacy policy is at [anonymax.app/privacy](https://anonymax.app/privacy/).

## This repository

This is the showcase, documentation and feedback home of AnonyMax. It contains no source code, no keys and no backend. Issues are public and hosted by GitHub under its own policies, so keep personal details out of them.
